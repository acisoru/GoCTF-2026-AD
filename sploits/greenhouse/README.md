# ОРАНЖЕРЕЯ · сплоиты

**Сервис:** `greenhouse` · **категория:** pwn / web / misc · **порт:** `8080`
**Где флаг:** приватные наблюдения (`pwn`), биометрическая заметка (`web`), архив спектров (`misc`).

> Держать приватно от команд. Это reference-эксплоиты автора.

## Эксплоиты

| Файл | Уязвимость | Запуск |
|------|------------|--------|
| `pwn.py`  | use-after-free в нативной консоли | `python3 pwn.py <host> <public_flag_id>` |
| `web.py`  | рассинхрон авторизации и рендера по фрагменту URL | `python3 web.py <host> <public_flag_id>` |
| `misc.py` | обратимая линейная рекуррента | `python3 misc.py <host> <public_flag_id>` |

## 1. Use-after-free (`pwn.py`)

**Суть.** `DROP` освобождает `Observation`, но оставляет типизированный хендл. `PollenPacket` того же размера переиспользует память, а `VIEW` затем интерпретирует байты пакета как старое наблюдение.

**Эксплуатация.** Дамп кадра, atlas и исполняемая таблица cultivar transform восстанавливают session nonce; пакету нужны валидные теги lineage и canopy.

**Патч.** Обнулять хендл при `DROP`, не оставляя висячую ссылку.

## 2. Фрагмент URL (`web.py`)

**Суть.** Обработчик проекции авторизует якорь до `#`, но рендерит фокус после `#`.

**Эксплуатация.** `public#<private-id>` с visitor-капабилити отдаёт приватную биометрическую заметку.

**Патч.** Резолвить капабилити по полному идентификатору (с фрагментом), а не по префиксу.

## 3. Линейная рекуррента (`misc.py`)

**Суть.** Публичный спектр — обратимая линейная рекуррента байт архива; калибровочная маска детерминирована от публичного plot ID.

**Эксплуатация.** Инверсия по модулю 257 восстанавливает исходный архив.

**Патч.** Не публиковать обратимое преобразование секрета; использовать настоящую случайность.

## Зависимости

Только стандартная библиотека Python 3.
