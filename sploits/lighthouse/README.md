# МАЯК · сплоиты

**Сервис:** `lighthouse` · **категория:** crypto · **порт:** `8085`
**Где флаг:** первое сообщение в публичном почтовом ящике (queue).

> Держать приватно от команд. Это reference-эксплоит автора.

## Эксплоиты

| Файл | Уязвимость | Запуск |
|------|------------|--------|
| `proof.py`        | chosen-plaintext атака на самодельный шифр | `python3 proof.py http://<host>:8085 <QUEUE_UUID>` |
| `feal_attack.cpp` | криптоанализ FEAL-подобного шифра (вызывается из `proof.py`) | компилируется `proof.py` через `g++` |

## 1. Chosen-plaintext на FEAL-подобный шифр

**Суть.** Сообщения шифруются самодельным блочным шифром FEAL-типа с малым числом раундов. По парам «выбранный открытый текст → шифртекст» восстанавливаются подключи.

**Эксплуатация.** `proof.py` открывает ящик и отправляет выбранные открытые тексты, `feal_attack.cpp` по собранным парам восстанавливает ключи и расшифровывает первое сообщение (флаг). На машине атакующего нужен `g++`.

**Патч.** Заменить самодельный шифр на стойкий с аутентификацией (например AES-GCM) либо существенно увеличить число раундов.

## Зависимости

Python 3 (stdlib) + `g++` на машине атакующего.
