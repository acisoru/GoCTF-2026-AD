# ОРАНЖЕРЕЯ (`greenhouse`)

**Категория:** pwn / web / misc · **стек:** Python backend + нативная консоль (ELF) + three.js фронтенд · **порт:** `8080`

Орбитальная оранжерея: веб-консоль управления наблюдениями, за которой стоит нативный бинарь.

## Запуск

```bash
docker compose up -d --build   # :8080
```
