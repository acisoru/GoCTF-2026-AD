# АСТРОЛЯБИЯ (`orbital_navigation`)

**Категория:** web-logic · **стек:** Rust · **порт:** `8086` (внутри контейнера `8080`)

Навигационный сервис орбитального флота: сообщения кораблей, манифесты, сводки, загрузка пакетов.

## Запуск

```bash
docker compose up -d --build   # :8086
```
